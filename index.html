Audio ML · Explainable AI · Collaborative
Vocal Emotion Detection — Speech Interpretability Metrics
CNN-based real-time speech emotion classification with MFCC features and Streamlit UI
→

A real-time Vocal Emotion Detection Application built using deep learning. Analyses speech/audio input and predicts the underlying human emotion using a Convolutional Neural Network (CNN) trained on labelled audio datasets. Extracts MFCC (Mel-Frequency Cepstral Coefficients) features and classifies the speaker's emotional state across 7 emotion classes through a clean Streamlit interface.

The project was collaboratively developed as a Final Year B.Tech Project alongside Saurav Kumar Singh. Features file upload for prediction, fast inference, and detailed evaluation visualisations including a confusion matrix.

Real-Time Face Mask Detection
MobileNetV2 + OpenCV live webcam detection pipeline

FinTech · Imbalanced Classification · Risk Analytics
Credit Card Fraud Detection — XGBoost
Imbalanced classification for financial fraud with business-critical metrics and live dashboard
→

An imbalanced classification model for financial fraud detection using XGBoost. Focused on business-critical metrics — Recall, Precision, PR-AUC, and ROC-AUC — and thoroughly explores the real-world trade-off between fraud capture rate and false positive costs.

Addresses the core challenge of imbalanced financial data using SMOTE oversampling and threshold optimisation. Directly applicable to risk, compliance, and fraud analytics roles.

Extends into an interactive Streamlit dashboard for financial risk analytics: displays transaction data, fraud probability scores, customer risk tiers, and behavioural charts — with a one-click downloadable CSV report for stakeholder reporting. Deployed live on Streamlit Community Cloud.
