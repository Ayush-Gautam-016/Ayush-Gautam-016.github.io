## Projects Featured

### 1 · Vocal Emotion Detection — Speech Interpretability Metrics
> **Repo:** [Speech-Interpretability-Metrics](https://github.com/Ayush-Gautam-016/Speech-Interpretability-Metrics)

Real-time speech emotion classification using a CNN trained on MFCC audio features. Detects 7 emotion classes (Angry, Calm, Happy, Sad, Fearful, Disgust, Neutral) via a Streamlit web app. Supports audio file upload and provides detailed evaluation including confusion matrix visualisation.

- **Stack:** Python · TensorFlow/Keras · Librosa · MFCC · CNN · NumPy · Streamlit
- **Type:** Collaborative Final Year B.Tech Project
- **Co-author:** [Saurav Kumar Singh](https://github.com/SauravB210489CS/emotion-app)

---

### 2 · Real-Time Face Mask Detection
> Computer Vision · Transfer Learning

Real-time face mask detection from webcam video using MobileNetV2 (transfer learning) and OpenCV. Draws bounding-box predictions per frame for instant visual feedback. Lightweight enough for edge/production deployment without GPU constraints.

- **Stack:** Python · TensorFlow/Keras · OpenCV · MobileNetV2 · Transfer Learning

---

### 3 · Credit Card Fraud Detection + Financial Risk Dashboard
> **Live Dashboard:** [ayush-gautam-fraud-risk-dashboard.streamlit.app](https://ayush-gautam-fraud-risk-dashboard.streamlit.app/)

Imbalanced classification model for financial fraud detection using XGBoost. Focuses on business-critical metrics (Recall, Precision, PR-AUC, ROC-AUC) and explores the trade-off between fraud capture rate and false positive costs. Includes a live interactive Streamlit dashboard with transaction-level risk scoring, customer segmentation, and downloadable CSV reports.

- **Stack:** Python · R · XGBoost · SMOTE · Streamlit · Pandas · Plotly
- **Deployment:** Streamlit Community Cloud
